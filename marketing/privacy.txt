SEO Checklist Privacy Policy
Last Updated: August 2026

1. What SEO Checklist Reads
----------------------------
When you click the extension icon and run an analysis, SEO Checklist reads the currently active tab's page content -- title, meta tags, headings, images, and hyperlinks -- to generate your on-page SEO checklist and score. This happens entirely inside your browser.

SEO Checklist does NOT collect, store, or transmit any of the following to us or anyone else:
- Personal user information (name, email, identifiers)
- Authentication information (passwords, credentials)
- Location, financial, or health data
- Browsing history -- only the single active tab is read, and only when you trigger an analysis
- User activity such as clicks, scrolling, or keystrokes

Analysis results (score, checklist, links, image lists) exist only in the popup's memory while it's open and are discarded when the popup closes. Nothing is written to persistent storage and nothing is sent to any server we operate.

2. Outbound Requests (Broken Link & Image Checks)
--------------------------------------------------
To check for broken internal links and oversized images, SEO Checklist makes direct HEAD/GET requests from your browser to the link and image URLs found on the page you are analyzing -- the same URLs your browser would request if you clicked them yourself. This is why the extension requests broad host permissions (http://*/*, https://*/*): it doesn't know in advance which domains a given page will link to or load images from.

These requests go directly from your browser to those third-party servers -- they are never routed through, logged by, or visible to us.

3. External Testing Tools
--------------------------
When you click the "Test Recent URL" buttons (Structured Data, PageSpeed Insights, Facebook Debugger, or LinkedIn Post Inspector), you are redirected to Google, Facebook, or LinkedIn's own tools, with your current page URL passed along so the tool can pre-fill it. These are external services with their own privacy policies; we do not control or access any data they collect.

4. Permissions Explanation
----------------------------
SEO Checklist uses only the permissions required for its features:
- activeTab: Access the currently active page only after you click the extension
- scripting: Run analysis code on the active tab to evaluate on-page SEO elements
- host_permissions (http://*/*, https://*/*): Allows the extension to check whether links and images found on the analyzed page are broken or oversized (see Section 2)
- notifications: Show a local, on-device notification when a new extension version is installed -- no data is transmitted to generate this notification
